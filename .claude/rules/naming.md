# 命名規約

- React コンポーネントファイル: **PascalCase** (`Template.tsx`)
- ユーティリティ・フック: **camelCase** (`utils.ts`, `useXxx.ts`)
- ディレクトリ: **小文字** (`components/`, `lib/`, `hooks/`)
- CSS ファイル: **camelCase** (`globals.css`)
- 設定ファイル: ツール標準に従う (`next.config.ts`, `eslint.config.mjs`)
- パスエイリアス `@/*` → `./src/*` を常に使用
